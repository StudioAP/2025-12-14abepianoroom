# ABE_PIANO_ADS_2026

安部ピアノルーム向けの広告紙面 3 案です。  
すべて A5 縦相当の 1 枚紙を想定した HTML マスターで、実ブランドの写真・配色・文言を基に構成しています。

## コンセプト

- `abe_piano_ad_concept_01_room-led.html`
  - 教室そのものの静けさと実在感を見せる総合案
- `abe_piano_ad_concept_02_restart.html`
  - 大人向けに絞り、「初めてでも、もう一度でも」を前面に出す案
- `abe_piano_ad_concept_03_gentle-pace.html`
  - 「生活に合わせて続ける」感覚をやわらかく見せる情緒案
